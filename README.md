## 🚀 Key Features

1. **Quick Question Dropdown & Live Search**:
   - A sticky header with a dropdown menu allowing instant jumping to any of the 50 questions.
   - Smooth scrolling with a subtle pulsing animation that highlights the selected question card.
   - Live search input to filter questions by keyword in real time.

2. **Category Tabs**:
   - Filter questions by section:
     1. Arrays (Questions 1 – 10)
     2. Arrays of Strings / Names (Questions 11 – 20)
     3. Objects (Questions 21 – 30)
     4. Strings (Questions 31 – 40)
     5. HTML Elements & DOM Manipulation (Questions 41 – 50)

3. **Interactive Testing Playgrounds**:
   - Every question includes a **💡 How to test:** guide with step-by-step instructions.
   - Interactive input fields, test buttons, reset actions, and live output containers.

4. **Collapsible Source Code Viewer**:
   - Each card contains a `<details>` block where examiners can inspect the clean JavaScript function for each problem.

5. **Aesthetic Light / Dark Mode**:
   - Clean theme switcher with persistent user preference stored in `localStorage`.
